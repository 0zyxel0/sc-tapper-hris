# Project Brief

## Project Name
sc-trapper-hris

## Overview
A Human Resources Information System (HRIS) backend built using Strapi, a headless CMS. This system is designed to manage employee data, organizational structure, roles, permissions, and other HR-related administrative tasks.

## Core Requirements & Goals
- Provide a robust API for managing HR records (employees, departments, attendance, leaves, etc.).
- Utilize Strapi's built-in role-based access control (RBAC) to manage user permissions.
- Provide an extensible admin panel (using React/TypeScript) for HR administrators to manage the platform.
- Serve as the central data hub for any frontend applications or internal tools interacting with HR data.

## Scope
Current scope includes initial configuration of the Strapi v5 instance and subsequent modeling of the database schema for the HRIS.
