# System Patterns

## Architecture
The system follows a Headless CMS architecture powered by Strapi.
- **Backend:** Node.js server running Strapi v5.
- **Database:** PostgreSQL.
- **Admin Panel:** React-based UI provided by Strapi, customizable via `src/admin`.
- **API:** RESTful endpoints automatically generated by Strapi based on content types.

## Design Patterns
- **Content-Type Modeling:** Data structures are defined as Content-Types in Strapi, which automatically generate database schemas and API endpoints.
- **MVC-like Structure:** Handled by Strapi's core (Controllers, Services, Routes) which can be overridden or extended in the `src/api` directory.
- **Role-Based Access Control (RBAC):** Utilizing Strapi's `@strapi/plugin-users-permissions` for API access and internal admin roles for dashboard access.

## Code Organization
- `src/api/`: Custom business logic, controllers, and services.
- `src/admin/`: Admin panel customizations (React/Vite).
- `src/extensions/`: Plugin extensions.
- `config/`: Environment and server configurations.
